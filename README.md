# MAFIA — The Game

Responsive, animated recreation of a supplied website reference. Built with HTML, CSS and JavaScript. Hosted on GitHub Pages from the main branch /docs folder.

## Features
- Responsive desktop and mobile layouts
- Animated section reveals and hover effects, with reduced-motion support
- Edition comparison and local cart/wishlist persistence
- Search, story dialog and media gallery
- Accessible dialogs, keyboard navigation and mobile menu

A visual demonstration only. Purchases, authentication, multiplayer and newsletter delivery are not connected. No personal information is submitted.

## Run
Serve the repository using any static HTTP server, or open docs/index.html. No build is required. All paths are relative and work under a GitHub Pages project path.

## Assets
Original generated monochrome imagery created with ImageGen. The supplied source screenshot is not included in this repository.

Hero prompt: full-body 1930s gangster walking in profile, fedora and black overcoat, holding a Thompson downward; transparent cutout, grayscale presentation.

Scenes prompt: cinematic monochrome contact sheet with a seated crime boss smoking, a night skyline, vintage car, gangster crew, character portraits and vintage weapons/money still life.
